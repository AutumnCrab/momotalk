# 모모톡 데스크톱 위젯 (MomoTalk Desktop Widget)

블루 아카이브의 '모모톡' UI를 바탕화면 위젯으로 만든 프로그램입니다.
캐릭터가 **요일·시간대별로** 정해진 대사를 보내오고, 안 읽은 메시지는
빨간 배지로 표시됩니다.

> 현재 단계: **1단계 — 우측 하단 떠다니는 아이콘 + 안 읽음 배지**

---

## 1. 준비물 (처음 한 번만)

1. 파이썬 설치 — https://www.python.org/downloads/
   - 설치 화면에서 **"Add Python to PATH"** 체크박스를 꼭 켜세요.
2. 설치 확인 — 터미널(Windows는 PowerShell)에서:
   ```
   python --version
   ```
   숫자가 나오면 성공입니다.

## 2. 라이브러리 설치

이 폴더(`momotalk-widget`) 안에서 터미널을 열고:

```
pip install -r requirements.txt
```

## 3. 실행

```
python main.py
```

실행하면 화면 **우측 하단**에 핑크색 말풍선 아이콘이 뜹니다.
약 4초 뒤 테스트 메시지가 1개 도착해 빨간 배지가 나타납니다.

| 동작 | 방법 |
|------|------|
| 채팅창 열기 | 아이콘 **더블클릭** |
| 위치 옮기기 | 아이콘 드래그 (손을 떼면 가까운 좌/우 가장자리에 붙음) |
| 읽음 처리(배지 숨김) | 아이콘 한 번 클릭 |
| 테스트 메시지 / 채팅창 / 종료 | 아이콘 **우클릭** → 메뉴 |
| 채팅창 닫기 | 헤더의 ✕ 또는 Esc |

---

## 4. 대사 편집하기 — `data/dialogues.json` (메모장으로 수정)

`data/dialogues.json` 을 메모장(또는 VS Code)으로 열어 대사를 추가/수정합니다.
저장 후 프로그램을 다시 실행하면 반영됩니다.

한 캐릭터의 형태:

```json
"shiroko": {
  "name": "시로코",
  "profile_img": "assets/profiles/shiroko.png",
  "schedule": [
    { "day": "everyday", "time": "07:00", "messages": ["좋은 아침이에요.", "오늘도 잘 부탁해요."] },
    { "day": "wed",      "time": "19:00", "messages": ["오늘 훈련은 여기까지."] }
  ]
}
```

- **`day`** 에 쓸 수 있는 값:
  - 요일: `mon` `tue` `wed` `thu` `fri` `sat` `sun` (한글 `월`~`일` 도 가능)
  - 묶음: `everyday`(매일) · `weekday`(평일) · `weekend`(주말)
  - 여러 요일: `["mon", "wed", "fri"]` 처럼 배열로
- **`time`** 은 24시간제 `"시:분"` (예: `"07:00"`, `"19:30"`)
- **`messages`** 는 보낼 대사 배열. 여러 줄이면 연달아 도착합니다.
- 한 시각마다 `{ ... }` 한 줄(엔트리). **월 7시·15시 / 수 9시**처럼 나누려면
  엔트리를 그만큼 추가하면 됩니다.

> ⚠️ JSON 규칙 두 가지만 지키면 됩니다: ① 문자열은 큰따옴표 `"`,
> ② 항목 사이 쉼표 `,` (마지막 항목 뒤에는 쉼표 없음).
> 저장 후 실행 시 오류가 나면 쉼표/따옴표를 확인하세요.

> 테스트할 때는 굳이 그 시각까지 기다리지 말고, 아이콘 **우클릭 → "테스트 메시지 받기"** 로
> 아무 대사나 즉시 받아볼 수 있습니다.

---

## 5. 잘 안 보일 때 (문제 해결)

- 실행하면 터미널에 `[모모톡] 준비 완료!` 같은 줄이 여러 개 떠야 정상입니다.
  화면 **우측 하단**(작업표시줄 바로 위)을 보세요.
- 만약 그 줄들은 떴는데 아이콘이 안 보이면, 터미널에 찍힌
  `[모모톡] 아이콘 위치: ...` 줄을 복사해서 알려주세요.
- 종료: 아이콘 **우클릭 → 종료**, 또는 터미널에서 **Ctrl + C**.

## 6. 폴더 구조

```
momotalk-widget/
├── main.py                  # 실행 진입점 (전체 연결 + 메시지 저장소)
├── requirements.txt         # 필요한 라이브러리 목록
├── momotalk/                # 프로그램 코드
│   ├── theme.py             # 색상·크기 상수 (여기서 디자인 조정)
│   ├── icon_widget.py       # 우측 하단 아이콘 위젯
│   ├── chat_window.py       # 채팅창 (목록 + 대화)
│   ├── scheduler.py         # 요일/시간 스케줄러
│   ├── data_loader.py       # dialogues.json 읽기
│   └── avatar.py            # 프로필 동그랗게 자르기
├── data/
│   └── dialogues.json       # 캐릭터 대사 데이터 (요일/시간 스케줄)
└── assets/
    ├── profiles/            # ← 학생 프로필 이미지를 여기에 넣으세요
    └── fonts/               # (선택) 폰트
```

## 7. 이미지(원본 사진)는 어디에 넣나요?

- **학생 프로필 사진** → `assets/profiles/` 폴더.
  - 정사각형(1:1) PNG 권장, 256×256 이상.
  - 파일명은 `data/dialogues.json` 의 `profile_img` 값과 똑같이.
    (예: `assets/profiles/shiroko.png`)
- **모모톡 로고(핑크 말풍선+하트)** 는 코드로 직접 그리므로 이미지가 필요 없습니다.

## 8. 앞으로의 단계 (로드맵)

1. ✅ 우측 하단 아이콘 + 안 읽음 배지
2. ✅ 아이콘 **더블클릭 → 채팅 목록 + 대화창** UI (+ 2단 테두리, 가장자리 스냅)
3. ✅ `dialogues.json` 기반 **요일/시간 스케줄러** (월 07:00, 수 09:00 …)
4. 캐릭터별 성격·어조를 쉽게 편집하는 구조 정리 / 받은 메시지 저장(재실행 후에도 유지)  ← **다음 차례**
5. PyInstaller로 **.exe 빌드** 후 배포

> 프로필 사진은 이제 `assets/profiles/` 에 넣으면 목록과 대화창에 바로 표시됩니다.
> (파일명은 `dialogues.json` 의 `profile_img` 값과 동일하게, 예: `shiroko.png`)
